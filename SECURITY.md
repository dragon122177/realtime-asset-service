# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the repository owner. Include reproduction
steps, the affected endpoint or workflow, and likely impact. Do not open a public issue containing
credentials, private models, customer data, or signed storage URLs.

## Demonstration boundary

ForgeFlow contains only synthetic projects, accounts, assets, and audit events. The bundled cube
is generated geometry and the demo credentials are local-only. Production deployments must use a
secret manager, private object storage, malware scanning, and organization-specific retention.
